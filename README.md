# Pharmaceutical Quality Control Dashboard

## 📌 Project Overview

A 4-page interactive Power BI dashboard developed to analyze pharmaceutical laboratory batch data and quality performance.

The project demonstrates how Power BI can be used to monitor quality metrics, identify trends, and support data-driven decision-making.

## 🎯 Business Questions

- What is the overall batch pass rate?
- How are OOS results changing?
- Which products show quality issues?
- How do assay, impurity, and dissolution results vary?
- How is analyst performance distributed?
- Which batches require attention?

## 📊 Dashboard Analysis

- Quality Overview
- Quality Analysis
- Analyst Performance
- Batch Details
- Pass Rate
- OOS Trends
- Assay
- Impurity
- Dissolution
- Batch-level analysis

## 🛠️ Tools

- Power BI
- DAX
- Power Query
- Microsoft Excel
